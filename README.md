## Track 2 Custom Game Assets
For my theme, I chose SIGNALIS, which is a survival horror game I love. I drew a pretty simple 60x60 pixel art version of the Penrose ship to replace the original spaceship.

I also made some corrupted Storch plushie sprites to replace the aliens, but those are going to be part of Milestone 2.
